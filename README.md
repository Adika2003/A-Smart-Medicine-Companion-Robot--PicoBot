# A-Smart-Medicine-Companion-Robot--PicoBot
PicoBot is a low-cost companion robot that helps elderly and chronically ill people take medicines on time. It provides voice reminders, touch-based confirmation, empathetic interaction, and gas-leak detection with emergency SMS alerts.
